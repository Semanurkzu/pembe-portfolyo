# Pembe Portfolyo

Semanur Kuzu için hazırlanan, 2026 tasarım yaklaşımına sahip modern ve responsive kişisel portfolyo sitesi.

## Öne çıkanlar

- Editoryal, mobil uyumlu tek sayfa tasarımı
- Açık/koyu tema ve tema tercihini hatırlama
- Erişilebilir klavye odağı, semantik HTML ve azaltılmış hareket desteği
- Mobil navigasyon ve kaydırma sırasında içerik geçişleri
- Dört GitHub projesinin doğrulanmış içeriklerle sunumu
- Manisa Celal Bayar Üniversitesi eğitim bilgisi ve güncel iletişim kanalları
- Harici kütüphane gerektirmeyen hızlı statik yapı

## Kullanılan teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript

## Çalıştırma

Projeyi yerel bir HTTP sunucusu ile açın:

```bash
python -m http.server 4173
```

Ardından tarayıcıda `http://localhost:4173` adresine gidin.
